# AI Travel Agent

## 项目介绍

基于 Dify 开发的 AI 旅游规划助手。

## 功能

- 查询天气
- 推荐景点
- 一日游规划
- Wikipedia 查询

## 技术栈

- Dify
- GPT-5.6
- OpenWeather
- Wikipedia Tool
